## Projeto em foco

### Pixelmon GTS Signal

Sistema que acompanha o GTS Global do Pixelmon em tempo real, captura anúncios, enriquece dados do hover do chat e envia alertas para Discord, Telegram e painel web.

**Stack principal:** Python, Ruby, Sinatra, ERB, HTMX, SQLite, Forge 1.12.2, systemd e Cloudflare Tunnel.

**Features que já funcionam:**

- feed ao vivo do GTS Global;
- alertas por item, vendedor, moeda, preço, TXT, IV mínimo e HA;
- radar de texturas customizadas;
- histórico permanente com comparação de preço;
- bot Discord com mensagem oficial fixada;
- Telegram;
- painel admin com usuários, convites e saúde dos serviços.

[Abrir repositório](https://github.com/TopDarkFlames/pixelmon-gts-signal)

## Em desenvolvimento

- ranking de texturas raras;
- score automático de preço bom/caro;
- exportação do histórico por período;
- relatórios semanais de preço e volume.
